# Voice Prep Studio

OpenAI のカスタム音声登録に向けて、本人の同意音声と声のサンプルを録音する日本語のローカルツールです。API キーや追加 npm パッケージは不要です。録音・保存・書き出しはブラウザー内で完結します。

## 起動

Windows では **`start.cmd` をダブルクリック**するとサーバーがバックグラウンドで起動し、既定のブラウザーで開きます。Node.js 18 以上が必要です。

ターミナルから起動する場合：

```powershell
cd D:\codex\openai_voice
npm start
```

**http://127.0.0.1:4317** を Chrome / Edge で開きます。ターミナルで起動したサーバーは Ctrl+C で停止できます。HTML ファイルを直接開かず、上記の localhost URL を使ってください。

`start.cmd` のバックグラウンドサーバーを止める場合は、タスクマネージャーの「詳細」で、コマンドラインがこのフォルダーの `server.mjs` になっている Node.js プロセスを終了します。他の Node.js プロセスとは区別してください。

## 使い方

1. 「録音の準備」でマイクを選び、「マイクをテスト」で入力を確認します。ブラウザーのマイク権限を許可してください。テストの音は保存しません。
2. 「同意音声」で本人が指定文だけを読みます。録音は3秒のカウントダウン後に開始します。
3. 「声のサンプル」で再現したい声を録ります。編集可能な日本語の原稿を用意しています。自然な速さで10〜30秒を目安に話してください。
4. 試聴してテイクを選び、「確認・書き出し」で2項目を確認し、ZIPを保存します。各テイクを個別にWAV保存することもできます。

ZIPには `consent.wav`、`sample.wav`、`recording-info.json`、`README.txt` が入ります。原稿は読み上げ用テキストとして記録され、実際の文字起こしではありません。音声データは加工・正規化・無音削除せず、モノラル16-bit PCM WAVとして出力します。ブラウザーには48 kHzを指定します。機器とブラウザー間でサンプルレート変換が行われる場合があります。

## 公式ガイドとの対応

参照：<https://developers.openai.com/api/docs/guides/custom-voices>（2026-09-12確認）

- 同意音声とサンプルは別ファイル・同じ本人。日本語の同意文は公式の指定文を固定表示します。
- サンプル上限30秒に対し、音声処理側で29.9秒のフレーム数を上限にしています。タイマーがバックグラウンドで遅れても録音の長さが超過しません。
- ガイドの GPT-Live 向け準備要件では、5秒以上の実発話・15トークン以上に相当する内容を含む10〜30秒のサンプル、各アップロード10 MiB以下が示されています。本ツールでは十分な長さの複数文の原稿を用意しています。29.9秒・48 kHz・モノラル16-bit WAVは約2.74 MiBです。
- 実発話時間・トークン数・同意文の一致・話者の一致・登録可否は自動検証しません。音量から算出する `activeSeconds` は音のある区間の概算で、発話時間ではありません。
- 音量不足とクリッピングの表示は簡易的な目安です。ノイズ・反響・発話内容は試聴で確認してください。
- 自動音量・ノイズ抑制・エコー除去のOFFを要求し、ブラウザーが報告した実設定を表示します。マイクやOS側の音声処理まで無効にするものではありません。
- カスタム音声の利用資格はOpenAI側で必要です。登録にはAPIから同意音声、続いてそのIDとサンプルを送ります。このアプリは音声を準備するためのもので、申請やAPI送信は行いません。

## 保存とマイク

テイクはIndexedDB、名前・原稿・選択状態はlocalStorageに保存します。同じブラウザー・同じオリジン（`127.0.0.1:4317`）で再度開くと復元します。`localhost` や別ポート、別のブラウザーは別の保存領域です。ブラウザーのサイトデータ消去、プライベートモード、空き容量不足では消失する場合があります。録音後はWAV / ZIPでも保存してください。保存に失敗すると画面で通知します。

マイクは停止・キャンセル・画面移動・ページ終了で解放します。録音中の試聴と画面移動は無効にしています。ブラウザーが録音を中断した場合は取得済み音声を保存し、確認を促します。

マイクが使えない場合はアドレスバーのサイト設定と、Windowsの「設定 → プライバシーとセキュリティ → マイク」を確認してください。埋め込みブラウザーで許可できない場合は、通常のChrome / Edgeで同じURLを開いてください。

## 開発・検証

```powershell
npm test
```

Node.js標準のテスト機能でWAVの形式、ZIPの整合性、録音上限、停止時のデータ保持、簡易品質チェック、ローカルHTTPサーバーを検証します。`tests/browser-smoke.mjs` はPlaywrightとChromiumがある環境で使うブラウザーテストです。テスト用の音声入力だけを使い、実際のマイクは使いません。

録音画面には外部ライブラリ、CDN、解析タグ、外部通信はありません。サーバーは `127.0.0.1` にのみバインドし、公開用ファイルだけを配信します。

## APIでカスタム音声を登録

`recordings/my-voice/consent.wav` と `sample.wav` を登録するコマンドを用意しています。録音画面とは別のCLIからOpenAI APIに音声を送信します。

1. プロジェクト直下の `.env` の `OPENAI_API_KEY=` にAPIキーを入力・保存します。特定のプロジェクトや組織を明示する場合は `OPENAI_PROJECT_ID` / `OPENAI_ORG_ID` も設定します。環境変数が設定済みの場合は環境変数を優先します。
2. `npm run voice:check` で設定の有無とWAV形式を確認できます。このコマンドは通信しません。
3. `npm run voice:create` で同意音声、続いて声のサンプルを登録します。

結果の同意ID・Voice IDは `recordings/my-voice/registration.json` に保存します。再実行時は保存済みのIDを使い、完了した登録を繰り返しません。通信途絶やサーバーエラーで成否不明になった場合は自動再送を止めるため、API側の状況を確認してください。実行中にプロセスが終了した場合は `.registration.lock` が残るので、実行プロセスがないことと登録状況を確認してから解除します。

`.env` と録音フォルダーはGitの追跡対象外です。APIキーはログやブラウザーへ出力しません。認証設定の取り違えを防ぐため、登録記録には認証設定全体のSHA-256を保存します。キーを変更した場合は自動続行しません。

登録APIのテストは `npm run test:registration` です。モック応答を使うため、APIには接続しません。
